# 🗑️ AI 垃圾分类识别系统 (Rubbish Recognition)

一个基于 HTML5 + JavaScript 的轻量级前端应用。只需配置你的 AI API Key，即可通过上传图片或拍照，利用大语言模型的视觉能力自动识别垃圾类型并提供分类建议。

---

## ✨ 项目特点

* **纯前端实现**：无需配置复杂的后端服务器，开箱即用。
* **AI 智能识别**：使用kimi大模型，精准识别垃圾属性。
* **双模式输入**：支持**拍照上传**与**本地图片选择**。
* **秒级响应**：即时获取垃圾分类结果（可回收物、有害垃圾、厨余垃圾、其他垃圾）及处理建议。
